# Gravatars Group website

Hugo source for https://the-gravatars.github.io/

## Publishing
Under Settings → Pages, select **GitHub Actions** as the build source. The included workflow builds the site from the main branch.

## Local development
Install Hugo Extended (v0.136.5 or compatible), then run `hugo server`.

## Updating
Edit the Markdown pages under `content/`. The homepage is in `layouts/index.html`, and the stylesheet is in `static/css/style.css`.

This is a starter site. Review people, publications, and other placeholders before public launch.
